## Abstract

A communication control apparatus includes: an overlapping area identification unit that identifies an overlapping area of a first location registration area including at least one terrestrial communication cell provided on the ground by a terrestrial base station installed on the ground and a second location registration area including at least one non-terrestrial communication cell provided on the ground by a flying non-terrestrial base station; a connection detection unit that detects that a communication device in the overlapping area is connected to one base station of the terrestrial base station and the non-terrestrial base station; and a connection change restriction unit that restricts change of connection destination of the communication device from the one base station to the other base station of the terrestrial base station and the non-terrestrial base station while the communication device is in the overlapping area.

## Description

This application is a National Stage of PCT international application No. PCT/JP2021/041153 filed on Nov. 9, 2021, which claims priority to Japanese application No. 2021-093455 filed on Jun. 3, 2021 and Japanese application No. 2021-098488 filed on Jun. 14, 2021.

The present disclosure relates to communication control technology in communication system.

The number, types, and applications of wireless communication devices, represented by smartphones and Internet of Things (IoT) devices, continue to increase, and wireless communication standards continue to be expanded and improved. For example, the commercial service of the fifth generation mobile communication system known as “5G” started in 2018, and the standards are still being developed by the 3GPP (Third Generation Partnership Project). Efforts are also underway to develop standards for “6G” or the sixth generation mobile communication system, which would be the next generation of wireless communication standards following 5G.

Mobile communication networks for mobile or portable communication devices such as smartphones and cell phones (hereinafter collectively referred to as “communication device (s)”) are usually constructed by communication cells (hereinafter referred to as “terrestrial communication cell (s)”) provided by base stations installed on the ground (hereinafter referred to as “terrestrial base station (s)”). However, in some areas, it was difficult to install a sufficient number of terrestrial base stations for various reasons, resulting in a relatively low quality of mobile communications.

In order to solve the problem of the disparity in mobile communication quality among different regions and the so-called “out-of-range” problem, where mobile communication devices cannot communicate in some regions, non-terrestrial networks (NTN) have been considered. In NTN, communication satellites or unmanned aircrafts flying in outer space or the atmosphere, such as the stratosphere, are used as base stations (hereinafter referred to as non-terrestrial base station (s), and especially communication satellites are referred to as satellite base station (s)). The non-terrestrial base station provides a communication cell on the ground (hereinafter referred to as non-terrestrial communication cell (s), and especially communication cells provided by communication satellites are referred to as satellite communication cell (s)). A communication device in a non-terrestrial communication cell communicates with a non-terrestrial base station directly or indirectly via other communication devices. By providing non-terrestrial communication cells in areas where terrestrial communication cells are not sufficient, the quality of mobile communication in such areas can be improved.

In a mobile communication system, a location registration area or a tracking area (TA) is provided to track or detect the approximate location of a communication device. The location registration area is composed of one or more base stations, and the entire area of each communication cell provided on the ground by each base station corresponds to the location registration area. For example, one mobile network operator (MNO) in Japan covers the entire country with several tens of location registration areas.

When a communication device moves across the boundaries of multiple location registration areas, an area change notification or location registration area update notification (TA Update: Tracking Area Update) is generated to notify the core network of the mobile communication system that the location registration area where the communication device is located has changed. In a communication system in which a terrestrial network (TN) composed of terrestrial base stations and a non-terrestrial network (NTN) composed of non-terrestrial base stations coexist, the location registration area to which a terrestrial base station belongs (hereinafter referred to as the first location registration area) and the location registration area to which a non-terrestrial base station belongs (hereinafter referred to as the second location registration area) may overlap. In the case where the connection destination of the communication device in the overlapping area is frequently switched between a terrestrial base station and a non-terrestrial base station, an area change notification is generated each time.

The present disclosure was made in consideration of this situation, and its purpose is to provide a communication control apparatus etc. that can prevent frequent changes of the location registration area or frequent area change notifications in the overlapping area of terrestrial communication cell and non-terrestrial communication cell.

In order to solve the above problem, a communication control apparatus in a certain aspect of the present disclosure comprises: an overlapping area identification unit that identifies an overlapping area of a first location registration area including at least one terrestrial communication cell provided on the ground by a terrestrial base station installed on the ground and a second location registration area including at least one non-terrestrial communication cell provided on the ground by a flying non-terrestrial base station; a connection detection unit that detects that a communication device in the overlapping area is connected to one base station of the terrestrial base station and the non-terrestrial base station; and a connection change restriction unit that restricts change of connection destination of the communication device from the one base station to the other base station of the terrestrial base station and the non-terrestrial base station while the communication device is in the overlapping area.

In this aspect, the connection change restriction unit restricts the change of the connection destination of the communication device in the overlapping area of the terrestrial communication cell and the non-terrestrial communication cell, so that the frequent change of the location registration area in the overlapping area can be prevented.

FIG. <b>1</b> schematically shows an overview of a wireless communication system <b>1</b> to which the communication control apparatus according to an embodiment of the present disclosure is applied. The wireless communication system <b>1</b> includes 5G wireless communication system <b>11</b>, 4G wireless communication system <b>12</b>, and satellite communication system <b>13</b>. 5G wireless communication system <b>11</b> that complies with the fifth generation mobile communication system (5G) uses NR (New Radio) or 5G NR (Fifth Generation New Radio) as the radio access technology (RAT) and 5GC (Fifth Generation Core) as the core network. 4G wireless communication system <b>12</b> that complies with the fourth generation mobile communication system (4G) uses LTE (Long Term Evolution) or LTE-Advanced as the radio access technology and EPC (Evolved Packet Core) as the core network. Satellite communication system <b>13</b> is for satellite communication via communication satellite <b>131</b>. Although not shown in the figure, the wireless communication system <b>1</b> may include wireless communication networks of a generation prior to 4G, a generation later than 5G (e.g. 6G), or any wireless communication networks that are not associated with generations, such as Wi-Fi (registered trademark).

The 5G wireless communication system <b>11</b> may include a plurality of 5G base stations <b>111</b>A, <b>111</b>B, and <b>111</b>C (hereinafter collectively referred to as 5G base station <b>111</b>) installed on the ground capable of communicating by 5G NR with communication devices or communication devices <b>2</b>A, <b>2</b>B, <b>2</b>C, and <b>2</b>D (hereinafter collectively referred to as communication device (s) <b>2</b>) such as smartphones, which are also referred to as UE (User Equipment). 5G base station <b>111</b> is also referred to as gNodeB (gNB). The coverage or support range of each 5G base station <b>111</b>A, <b>111</b>B and <b>111</b>C is referred to as a cell <b>112</b>A, <b>112</b>B and <b>112</b>C (hereinafter collectively referred to as 5G cell <b>112</b>).

The size of the 5G cell <b>112</b> of each 5G base station <b>111</b> is arbitrary, but typically ranges from a few meters to several tens of kilometers in radius. Although there is no established definition, cells with a radius of a few meters to ten meters are called femtocells, cells with a radius of ten meters to several tens of meters are called picocells, cells with a radius of several tens of meters to several hundred meters are called microcells, and cells with a radius of more than several hundreds of meters are called macrocells. In 5G, high frequency radio waves such as millimeter waves are often used, and their high tendency to propagate in a straight-line causes radio waves to be blocked by obstacles, shortening the communication distance. For this reason, 5G tends to use more small cells than 4G and earlier generations.

The communication device <b>2</b> can conduct 5G communication when it is located within at least one of a plurality of 5G cells <b>112</b>A, <b>112</b>B and <b>112</b>C. In the example shown in the figure, communication device <b>2</b>B in 5G cells <b>112</b>A and <b>112</b>B can communicate with both 5G base stations <b>111</b>A and <b>111</b>B by 5G NR. In addition, the communication device <b>2</b>C in the 5G cell <b>112</b>C can communicate with the 5G base station <b>111</b>C by 5G NR. Communication device <b>2</b>A and <b>2</b>D are outside of all 5G cells <b>112</b>A, <b>112</b>B and <b>112</b>C, so they are not able to communicate by 5G NR. The 5G NR-based 5G communication between each communication device <b>2</b> and each 5G base station <b>111</b> is managed by the 5GC, which is the core network. For example, the 5GC transfers data to and from each 5G base station <b>111</b>, transfers data to and from external networks such as the EPC, the satellite communication system <b>13</b> and the Internet, and manages the movement of the communication device <b>2</b>.

The 4G wireless communication system <b>12</b> comprises a plurality of 4G base stations <b>121</b> (only one of them is shown in FIG. <b>1</b>) installed on the ground that can communicate with the communication device <b>2</b> by LTE or LTE-Advanced. The base station <b>121</b> in 4G is referred to as eNodeB (eNB). Similarly to each 5G base station <b>111</b>, the communication range or support range of each 4G base station <b>121</b> is also called a cell and is shown as <b>122</b>.

The communication device <b>2</b> can conduct 4G communication when it is located within 4G cell <b>122</b>. In the example shown in the figure, the communication devices <b>2</b>A and <b>2</b>B in the 4G cell <b>122</b> can communicate with the 4G base station <b>121</b> by LTE or LTE-Advanced. Communication device <b>2</b>C and <b>2</b>D are outside the 4G cell <b>122</b> and are not able to communicate by LTE or LTE-Advanced. The 4G communication by LTE and LTE-Advanced between each communication device <b>2</b> and each 4G base station <b>121</b> is managed by the EPC, which is the core network. For example, the EPC manages the transfer of data to and from each 4G base station <b>121</b>, the transfer of data to and from external networks such as 5GC, the satellite communication system <b>13</b> and the Internet, and the movement management of the communication device <b>2</b>.

If we take a look at each communication device <b>2</b>A, <b>2</b>B, <b>2</b>C and <b>2</b>D in the example shown in the figure, the communication device <b>2</b>A is in a state that enables 4G communication with 4G base station <b>121</b>, and communication device <b>2</b>B is in a state that enables 5G communication with 5G base stations <b>111</b>A and <b>111</b>B and 4G communication with 4G base station <b>121</b>, and communication device <b>2</b>C is in a state that enables 5G communication with 5G base station <b>111</b>C. When there are multiple base stations (<b>111</b>A, <b>111</b>B and <b>121</b>) as in the case of communication device <b>2</b>B, one base station is selected as the most suitable for the communication device <b>2</b>B in terms of communication quality etc., under the control of the 5GC and/or the EPC, which is the core network. For the communication device <b>2</b>D that is not in a state that enables 5G communication with any 5G base station <b>111</b> or 4G communication with any 4G base station <b>121</b>, the communication is conducted using the satellite communication system <b>13</b> described below.

The satellite communication system <b>13</b> is the wireless communication system using communication satellites <b>131</b> as non-terrestrial base stations. The communication satellites <b>131</b> are low-earth-orbit satellites flying in low-earth-orbit outer space of 500 to 700 km above the ground. Similarly to 5G base station <b>111</b> and 4G base station <b>121</b>, the communication range or support range of each communication satellite <b>131</b> is also called a cell and is shown as <b>132</b>. Thus, a communication satellite <b>131</b> as a non-terrestrial base station provides a satellite communication cell <b>132</b> as a non-terrestrial communication cell onto the ground. Communication device <b>2</b> on the ground can conduct satellite communication when it is inside the satellite communication cell <b>132</b>. Similarly to 5G base station <b>111</b> in the 5G wireless communication system <b>11</b> and 4G base station <b>121</b> in the 4G wireless communication system <b>12</b>, communication satellite <b>131</b> as the base station in the satellite communication system <b>13</b> is capable of wireless communication directly or indirectly via aircraft etc. with the communication device <b>2</b> within the satellite communication cell <b>132</b>. The radio access technology used by the communication satellite <b>131</b> for wireless communication with the communication device <b>2</b> in the satellite communication cell <b>132</b> may be 5G NR, the same as the 5G base station <b>111</b>, or LTE or LTE-Advanced, the same as the 4G base station <b>121</b>, or any other radio access technology that the communication device <b>2</b> can use. Therefore, there is no need for the communication device <b>2</b> to have any special functions or components for satellite communication.

The satellite communication system <b>13</b> is equipped with a gateway <b>133</b> as a ground station that is installed on the ground and can communicate with the communication satellite <b>131</b>. The gateway <b>133</b> is equipped with a satellite antenna to communicate with the communication satellite <b>131</b>, and is connected to the 5G base station <b>111</b> and the 4G base station <b>121</b> as terrestrial base stations that constitute the terrestrial network (TN). In this way, the gateway <b>133</b> connects the non-terrestrial network (NTN), which is comprising communication satellites <b>131</b>, and the terrestrial network TN, which is comprising terrestrial base stations <b>111</b> and <b>121</b>, for mutual communication. When the communication satellite <b>131</b> conducts 5G communication with the communication device <b>2</b> in the satellite communication cell <b>132</b> by 5G NR, the 5GC connected via the gateway <b>133</b> and the 5G base station <b>111</b> in the TN (or the 5G radio access network) is used as the core network. When the communication satellite <b>131</b> conducts 4G communication with the communication device <b>2</b> in the satellite communication cell <b>132</b> by LTE or LTE-Advanced, the EPC connected via the gateway <b>133</b> and the 4G base station <b>121</b> in the TN (or the 4G radio access network) is used as the core network. In this way, appropriate coordination is made between different wireless communication systems such as 5G wireless communication system <b>11</b>, 4G wireless communication system <b>12</b>, satellite communication system <b>13</b> etc. through the gateway <b>133</b>.

Satellite communication by communication satellites <b>131</b> is mainly used for covering areas with no or few terrestrial base stations such as 5G base stations <b>111</b> and 4G base stations <b>121</b> etc. In the example shown in the figure, a communication device <b>2</b>D that is outside the communication cells of all the terrestrial base stations communicates with the communication satellite <b>131</b>. On the other hand, communication devices <b>2</b>A, <b>2</b>B and <b>2</b>C that are in good communication with either of the terrestrial base stations, are also in the satellite communication cell <b>132</b> and can communicate with the communication satellite <b>131</b>. However, by communicating with the terrestrial base stations instead of the communication satellite <b>131</b> as the satellite base station in principle, the limited communication resources (including power) of the communication satellite <b>131</b> are saved for the communication device <b>2</b>D etc. The communication satellite <b>131</b> uses beamforming to direct the communication radio wave to the communication device <b>2</b>D in the satellite communication cell <b>132</b>, thereby the communication quality with the communication device <b>2</b>D is improved.

The size of the satellite communication cell <b>132</b> of the communication satellite <b>131</b> as a satellite base station depends on the number of beams emitted by the communication satellite <b>131</b>. For example, a satellite communication cell <b>132</b> with a diameter of about 24 km can be formed by combining up to 2, 800 beams. As illustrated, a satellite communication cell <b>132</b> is typically larger than a terrestrial communication cell such as a 5G cell <b>112</b> or a 4G cell <b>122</b>, and could contain one or more 5G cells <b>112</b> and/or 4G cells <b>122</b> inside it. The above example shows a communication satellite <b>131</b> flying in low-earth-orbit outer space at a height of about 500 km to 700 km above the ground as a flying non-terrestrial base station. However, a communication satellite flying in geostationary orbit or other higher orbit in outer space, or an unmanned or manned aircraft flying in stratosphere or other lower (e.g. about 20 km above the ground) atmosphere may be used as a non-terrestrial base station in addition to or instead of the communication satellite <b>131</b>.

The communication control apparatus <b>3</b> has an estimation unit <b>301</b>, a connection detection unit <b>302</b>, an overlapping area identification unit <b>303</b>, a connection change restriction unit <b>304</b>, a connection control unit <b>305</b>, an area change detection unit <b>306</b>, an area change notification unit <b>307</b>, and a connection history information retention unit <b>308</b>. These functional blocks are realized by the cooperation of hardware resources, such as the central processing unit, memory, input devices, output devices, and peripheral devices connected to the computer, and software that is executed using them. Regardless of the type of computer or its installation location, each of the above functional blocks may be realized with the hardware resources of a single computer, or by combining hardware resources distributed across multiple computers. Especially in this embodiment, some or all of functional blocks of the communication control apparatus <b>3</b> may be realized in a distributed or centralized manner by computer and/or processor provided in the communication device <b>2</b> (e.g. <b>2</b>F), the terrestrial base stations <b>111</b>, <b>121</b>, the non-terrestrial base station <b>131</b>, and the core network CN (all of these are shown as separate entities in FIG. <b>3</b> for convenience).

In this embodiment, the first location registration area TA<b>1</b>, which is composed of terrestrial base stations, and the second location registration area TA<b>2</b>, which is composed of non-terrestrial base stations, are assigned different TAC or ID “#<b>1</b>” and “#<b>2</b>” respectively. In other words, the terrestrial communication cells provided on the ground by the terrestrial base station and the non-terrestrial communication cells provided on the ground by the non-terrestrial base station belong to different location registration areas TA<b>1</b> and TA<b>2</b> respectively. In this case, the communication device <b>2</b>F in the overlapping area OA of the first location registration area TA<b>1</b> and the second location registration area TA<b>2</b> can communicate with both the terrestrial base station in the first location registration area TA<b>1</b> and the non-terrestrial base station in the second location registration area TA<b>2</b>. If the connection destination of the communication device <b>2</b>F in the overlapping area OA is frequently switched between the terrestrial base station and the non-terrestrial base station, the location registration area to which the communication device <b>2</b>F belongs is changed each time, and the area change notification by the area change notification unit <b>307</b> described below is issued frequently. The communication control apparatus <b>3</b> of this embodiment prevents such frequent changes of the location registration area or frequent area change notifications in the overlapping area OA of terrestrial communication cells and non-terrestrial communication cells.

The estimation unit <b>301</b> estimates the connection status of the communication device <b>2</b>F in the overlapping area OA (e.g. to which of the terrestrial base stations or non-terrestrial base stations the communication device <b>2</b>F is connected) and its location (e.g. whether or not the communication device <b>2</b>F is in the overlapping area OA). The estimation unit <b>301</b> acquires information indicating the connection status and/or location of the communication device <b>2</b>F in the overlapping area OA from the communication device <b>2</b> (<b>2</b>F etc.), terrestrial base stations that constitute the first location registration area TA<b>1</b>, non-terrestrial base stations that constitute the second location registration area TA<b>2</b>, core network CN, any kind of database <b>4</b> outside the wireless communication system <b>1</b> etc.

For example, the information indicating the connection status and/or location of the communication device <b>2</b>F in the overlapping area OA may be obtained from the NWDAF (Network Data Analytics Function) and/or the LMF (Location Management Function) introduced in the 5GC as the core network CN of 5G. The NWDAF is responsible for collecting and analyzing data on the network including 5G network. Specifically, NWDAF collects and accumulates activity history data (including history information on the base station to which the communication device <b>2</b> was connected and the location of the communication device <b>2</b>) on various activities performed on the network by a number of communication devices <b>2</b> connected to the network, and utilizes the analysis results for traffic control on the network, for example. The LMF manages the physical location of each communication device <b>2</b> on the network including 5G network. In other wireless communication systems, including those of later generations than 5G, functions similar to NWDAF and/or LMF might be provided under different names. Such similar functions may be used in this embodiment in place of or in addition to NWDAF and/or LMF.

The database <b>4</b> outside the wireless communication system <b>1</b> includes a server used by service providers that provide map services and/or location tracking services for a large number of communication device <b>2</b> connected to the network, and the information indicating the location etc. of the communication device <b>2</b>F in the overlapping area OA may be also obtained from such database <b>4</b>. In these services, location data of a large number of communication device <b>2</b> connected to the network is collected and stored from GPS modules etc., and based on the analysis of the data, data on congestion level for each time period in each area, for example, is generated and utilized for service quality improvement etc.

As described above, from the core network CN (NWDAF etc.) and/or the database <b>4</b>, statistical information on the activities on the network by mainly an unspecified number of communication devices <b>2</b> (including statistical information on the base stations to which they are connected) and/or historical information on the physical locations of mainly an unspecified number of communication devices <b>2</b> can be acquired. In the example of FIG. <b>3</b>, the congestion level, communication traffic, and other activity history information for each time period in the overlapping area OA and the non-overlapping area (e.g. areas where the communication devices <b>2</b>E, <b>2</b>G are located) respectively, can be acquired by the estimation unit <b>301</b> from the core network CN and/or the database <b>4</b> as the information indicating the current connection status and/or current location of the communication device <b>2</b>F in the overlapping area OA. For example, during the time period when the estimation unit <b>301</b> estimates the current connection status and/or current location of the communication device <b>2</b>F, if the activity history information from the core network CN and/or the database <b>4</b> suggests that the number and/or communication volume of the communication devices <b>2</b> in the overlapping area OA are higher on average than the number and/or communication volume of the communication devices <b>2</b> in the non-overlapping area and/or that most of the communication devices <b>2</b> in the overlapping area OA were connected to the terrestrial base stations, it can be presumed that the communication device <b>2</b>F is likely to be in the overlapping area OA and be connected to the terrestrial base station (the first location registration area TA<b>1</b>).

In the case where the activity history information of the communication device <b>2</b>F itself can be obtained from the communication device <b>2</b>F itself, terrestrial base stations that constitute the first location registration area TA<b>1</b>, non-terrestrial base stations that constitute the second location registration area TA<b>2</b>, core network CN, database <b>4</b> etc., in addition to or instead of the activity history information of an unspecified number of communication devices <b>2</b> from the core network CN and/or the database <b>4</b>, it is possible to accurately estimate the connection status and/or the location of the communication device <b>2</b>F. For example, during the time period when the estimation unit <b>301</b> estimates the current connection status and/or current location of the communication device <b>2</b>F, if the acquired activity history information suggests that the communication device <b>2</b>F was more frequently in the overlapping area OA than in non-overlapping area in the past and/or that the communication device <b>2</b>F in the overlapping area OA was more frequently connected to the terrestrial base stations than the non-terrestrial base stations in the past, it can be presumed that the communication device <b>2</b>F is highly likely to be in the overlapping area OA and be connected to the terrestrial base station (the first location registration area TA<b>1</b>).

In addition to or instead of the activity history information on past days, the activity history information of the communication device <b>2</b>F immediately before (e.g. within one hour) the estimation unit <b>301</b> estimates the current connection status and/or current location of the communication device <b>2</b>F may be used. For example, if the acquired activity history information suggests that the communication device <b>2</b>F was in the overlapping area OA and connected to the terrestrial base station within 30 minutes before the estimation unit <b>301</b> estimates the current connection status and/or current location of the communication device <b>2</b>F, it can be presumed that the communication device <b>2</b>F is highly likely to remain in the overlapping area OA and be connected to the terrestrial base station (the first location registration area TA<b>1</b>).

In contrast to the NWDAF and/or the database <b>4</b>, which collect activity history information of mainly an unspecified number of communication devices <b>2</b>, the LMF can collect statistical information on the activities on the network by the specific communication device <b>2</b>F and/or historical information on the physical locations of the specific communication device <b>2</b>F. For example, during the time period when the estimation unit <b>301</b> estimates the current connection status and/or current location of the communication device <b>2</b>F, if the activity history information acquired from the LMF suggests that the communication device <b>2</b>F was more frequently in the overlapping area OA than in non-overlapping area in the past and/or that the communication device <b>2</b>F in the overlapping area OA was more frequently connected to the terrestrial base stations than the non-terrestrial base stations in the past, it can be presumed that the communication device <b>2</b>F is highly likely to be in the overlapping area OA and be connected to the terrestrial base station (the first location registration area TA<b>1</b>). And, if the activity history information acquired from the LMF suggests that the communication device <b>2</b>F was in the overlapping area OA and connected to the terrestrial base station within 30 minutes before the estimation unit <b>301</b> estimates the current connection status and/or current location of the communication device <b>2</b>F, it can be presumed that the communication device <b>2</b>F is highly likely to remain in the overlapping area OA and be connected to the terrestrial base station (the first location registration area TA<b>1</b>). The activity history information of the specific communication device <b>2</b>F as described above can be obtained from the GPS module or memory implemented in the communication device <b>2</b>F, terrestrial base stations that constitute the first location registration area TA<b>1</b>, non-terrestrial base stations that constitute the second location registration area TA<b>2</b> etc. by the estimation unit <b>301</b> directly.

If the connection status of the communication device <b>2</b>F, which is the target of the estimation of the estimation unit <b>301</b>, can be directly recognized in real time from the connection control unit <b>305</b> described below, the estimation unit <b>301</b> may not need to estimate the connection status of the communication device <b>2</b>F. In the same way, if the location of the communication device <b>2</b>F, which is the target of the estimation of the estimation unit <b>301</b>, can be directly recognized in real time from the GPS module etc. implemented in the communication device <b>2</b>F, the estimation unit <b>301</b> may not need to estimate the location of the communication device <b>2</b>F.

The connection detection unit <b>302</b> detects whether the communication device <b>2</b>F in the overlapping area OA is connected to a terrestrial base station that constitutes the first location registration area TAL or a non-terrestrial base station that constitutes the second location registration area TA<b>2</b>. The connection detection unit <b>302</b> may detect the base station to which the communication device <b>2</b>F in the overlapping area OA is connected, based on the connection status of the communication device <b>2</b>F estimated by the estimation unit <b>301</b> and/or the real-time connection status of the communication device <b>2</b>F recognized by the connection control unit <b>305</b>.

The overlapping area identification unit <b>303</b> identifies the overlapping area OA of the first location registration area TA<b>1</b> and the second location registration area TA<b>2</b>, and detects whether the communication device <b>2</b>F is in the overlapping area OA. The overlapping area identification unit <b>303</b> may judge whether the communication device <b>2</b>F is in the overlapping area OA, based on the location of the communication device <b>2</b>F estimated by the estimation unit <b>301</b> and/or the real-time location of the communication device <b>2</b>F recognized by the GPS module etc. implemented in the communication device <b>2</b>F.

The connection change restriction unit <b>304</b> restricts change of connection destination of the communication device <b>2</b>F from the one base station to the other base station of the terrestrial base station that constitutes the first location registration area TA<b>1</b> and the non-terrestrial base station that constitutes the second location registration area TA<b>2</b>, while it is confirmed by the overlapping area identification unit <b>303</b> that the communication device <b>2</b>F is in the overlapping area OA. For example, the connection change restriction unit <b>304</b> rejects at least one request for changing the connection destination to the other base station received from the communication device <b>2</b>F in the overlapping area OA. In addition, the connection change restriction unit <b>304</b> may notify the communication device <b>2</b>F in the overlapping area OA that the location registration area that includes the other base station is a transition prohibited area.

Specifically, when the communication device <b>2</b>F in the overlapping area OA is connected on the terrestrial base station that constitutes the first location registration area TA<b>1</b>, the change of the connection destination of the communication device <b>2</b>F to the non-terrestrial base station that constitutes the second location registration area TA<b>2</b> is restricted. Conversely, when the communication device <b>2</b>F in the overlapping area OA is connected on the non-terrestrial base station that constitutes the second location registration area TA<b>2</b>, the change of the connection destination of the communication device <b>2</b>F to the terrestrial base station that constitutes the first location registration area TAL is restricted. This restricts the change of the base station type of the connection destination which directly leads to the change of the location registration area while the communication device <b>2</b>F is confirmed to be in the overlapping area OA. In this way, this embodiment can prevent frequent changes of the location registration area in the overlapping area OA and frequent area change notifications by the area change notification unit <b>307</b> described below.

The connection control unit <b>305</b> connects each communication device <b>2</b> to each base station, and according to changes in the communication quality of each base station and/or the movement of each communication device <b>2</b>, changes the base station to be connected by each communication device <b>2</b>. As for the communication device <b>2</b>F in the overlapping area OA, the change of the base station type in the overlapping area OA is restricted as described above. However, when the communication quality of the base station of the one type being connected by the communication device <b>2</b>F within the overlapping area OA deteriorates extremely, or when the communication device <b>2</b>F moves outside the overlapping area OA (detected by the overlapping area identification unit <b>303</b>), it is allowed to change the connection destination to the base station of the other type.

The area change detection unit <b>306</b> detects a change of the location registration area to which each communication device <b>2</b> is connected. For example, if the communication device <b>2</b>F that was connected to the terrestrial base station that constitutes the first location registration area TA<b>1</b> in the overlapping area OA moves outside the overlapping area OA and to the area outside the first location registration area TA<b>1</b> and inside the second location registration area TA<b>2</b>, the connection control unit <b>305</b> shall connect the communication device <b>2</b>F to the non-terrestrial base station that constitutes the second location registration area TA<b>2</b>. In this case, the location registration area to which the communication device <b>2</b>F is connected is changed from the first location registration area TA<b>1</b> to the second location registration area TA<b>2</b>, which is detected by the area change detection unit <b>306</b>.

When a change of the location registration area connected by each communication device <b>2</b> is detected by the area change detection unit <b>306</b>, the area change notification unit <b>307</b> generates an area change notification (TA Update). The area change detection unit <b>306</b> and the area change notification unit <b>307</b> are typically provided in the communication device <b>2</b>F. Specifically, the communication device <b>2</b>F recognizes that it is connected to the second location registration area TA<b>2</b> based on the TAC “#<b>2</b>” included in the notification information transmitted by the non-terrestrial base station to which the connection has been changed. And, the communication device <b>2</b>F detects that its connected location registration area has been changed (area change detection unit <b>306</b>) based on the difference between the TAC “#<b>2</b>” and the TAC “#<b>1</b>” of the first location registration area TA<b>1</b> included in the notification information transmitted by the terrestrial base station from which the connection has been changed. Then, the communication device <b>2</b>F notifies the core network CN of the change of its connected location registration area in the form of an area change notification (area change notification unit <b>307</b>).

The connection history information retention unit <b>308</b> retains connection history information to the base station of the one type, when the connection destination of the communication device <b>2</b>F in the overlapping area OA is changed from the base station of the one type (e.g. terrestrial base station) to the base station of the other type (e.g. non-terrestrial base station). The connection history information retention unit <b>308</b>, which is typically provided in the communication device <b>2</b>F, retains the connection history information indicating that the communication device <b>2</b>F has been connected to the base station of the one type for at least a predetermined period of time. The area change notification unit <b>307</b> does not generate an area change notification, when the connection destination of the communication device <b>2</b>F is changed again from the base station of the other type to the base station of the one type for which the connection history information is retained, while the connection history information is being retained by the connection history information retention unit <b>308</b> and while it is confirmed by the overlapping area identification unit <b>303</b> that the communication device <b>2</b>F is in the overlapping area OA. For example, when the connection destination of the communication device <b>2</b>F in the overlapping area OA is changed from a terrestrial base station to a non-terrestrial base station and then changed again to a terrestrial base station, the area change notification from the second location registration area TA<b>2</b> (non-terrestrial base station) to the first location registration area TA<b>1</b> (terrestrial base station) will not be issued, based on the connection history information retained by the connection history information retention unit <b>308</b>. In this way, the frequent area change notifications in the overlapping area OA can be prevented.

FIG. <b>5</b> is a functional block diagram of the communication control apparatus <b>3</b> of the second embodiment. The communication control apparatus <b>3</b> comprises an estimation unit <b>301</b>, a connection detection unit <b>302</b>, and an overlapping area identification unit <b>303</b>, similar to those in the first embodiment (FIG. <b>3</b>), and additionally comprises a first paging control unit <b>309</b>, a second paging control unit <b>310</b>, and a base station type recording unit <b>311</b>. Duplicate descriptions of functional blocks common to the first embodiment will be omitted.

In this embodiment, the first location registration area TA, which is composed of terrestrial base stations <b>112</b> and <b>122</b>, and the second location registration area TA<b>2</b>, which is composed of non-terrestrial base stations <b>132</b>, are assigned the same TAC or ID “#<b>1</b>”. In other words, the first location registration area TA<b>1</b> and the second location registration area TA<b>2</b> constitute one large integrated location registration area TA<b>0</b> with the TAC or ID of “#<b>1</b>” assigned to it.

In general, when making a call or delivering a short message to a communication device in a location registration area, a paging signal to call the communication device is transmitted simultaneously from all base stations in the location registration area. Therefore, the paging signal to call communication devices <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b> is transmitted simultaneously not only from the terrestrial base stations <b>111</b> and <b>121</b> that constitute the first location registration area TA<b>1</b>, but also from the communication satellite <b>131</b> that constitutes the second location registration area TA<b>2</b>. Since the integrated location registration area TA<b>0</b> is a large area and contains a large number of base stations and communication devices, the network load for transmitting the paging signal increases. In addition, as mentioned above, communication devices <b>2</b> are generally connected to terrestrial base stations <b>111</b> and <b>121</b> preferentially. In many areas, the possibility of a communication device <b>2</b> being connected to a communication satellite <b>131</b> is considered to be relatively low. It is not desirable to waste the limited power generated from sunlight by the solar panels mounted on the communication satellite <b>131</b> for transmitting paging signals, which are considered to have a relatively low probability of call success. The communication control apparatus <b>3</b> of this embodiment can efficiently transmit a paging signal to the communication devices <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b> including at least one terrestrial communication cell and at least one non-terrestrial communication cell.

The estimation unit <b>301</b> as a base station estimation unit estimates base stations to which the communication devices <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b> is connected. The estimation unit <b>301</b> can be configured in the similar way to the estimation unit <b>301</b> of the first embodiment shown in FIG. <b>3</b>. The estimation unit <b>301</b> of the first embodiment estimates the connection status and/or location of the communication device <b>2</b>F in the overlapping area OA. On the other hand, the estimation unit <b>301</b> of the present embodiment estimates the type of the connected base station (terrestrial base station <b>111</b>, <b>121</b> or non-terrestrial base station <b>131</b>) as the connection status of the communication devices <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b> which is not necessarily the overlapping area OA. In the similar way to the first embodiment, the estimation unit <b>301</b> of this embodiment may estimate other connection statuses and locations of communication devices <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b>.

The estimation unit <b>301</b> estimates the type of the base stations to which the communication devices <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b>, based on at least one of the following: performance information, frequency capability information, contract information, location information, communication status information, activity history information of the communication devices <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b>, and activity history information of an unspecified number of communication devices <b>2</b> in the integrated location registration area TA<b>0</b>. These information indicating the type of base station to which the communication device <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b> can be obtained by the estimation unit <b>301</b> from the communication device <b>2</b> itself, the terrestrial base stations that constitute the first location registration area TA<b>1</b>, the non-terrestrial base stations that constitute the second location registration area TA<b>2</b>, the core network CN, any database <b>4</b> outside the wireless communication system <b>1</b> etc.

For example, performance information, frequency capability information, contract information, communication status information, activity history information of the communication devices <b>2</b> to be estimated, indicate capability and/or tendency of the communication device <b>2</b> for the terrestrial communication through the terrestrial base stations <b>111</b>, <b>121</b> and the non-terrestrial communication through the non-terrestrial base stations <b>131</b> respectively, and provide useful suggestion regarding the type of the base station to which the communication device <b>2</b> is connected. In addition, since the location of the communication device <b>2</b> in the integrated location registration area TA<b>0</b> can be detected or estimated, according to the location information of the communication device <b>2</b> to be estimated obtained from the LMF of the core network CN and/or the GPS module etc. of the communication device <b>2</b>. Therefore, it is possible to estimate or determine that, the communication device <b>2</b>E inside the first location registration area TA<b>1</b> and outside the overlapping area OA is connected to the terrestrial base station <b>111</b>, <b>121</b>, and the communication device <b>2</b>G and <b>2</b>H inside the second location registration area TA<b>2</b> and outside the overlapping area OA are connected to the non-terrestrial base station <b>131</b>. For the communication device <b>2</b>F in the overlapping area OA, the same as in the first embodiment, the estimation unit <b>301</b> estimates the type of the connected base station, by referring to the activity history information of an unspecified number of communication devices <b>2</b> obtained from the NWDAF in the core network CN and/or the database <b>4</b>. The connection detection unit <b>302</b> detects the base station (its type) to which the communication devices <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b> are connected, while also referring to the estimation results of the estimation unit <b>301</b>. The overlapping area identification unit <b>303</b> identifies the overlapping area OA of the first location registration area TA<b>1</b> (terrestrial communication cells <b>112</b>, <b>122</b>) and the second location registration area TA<b>2</b> (non-terrestrial communication cell <b>132</b>), and detects the communication device <b>2</b>F in the overlapping area OA.

The first paging control unit <b>309</b> causes base station of the one type of the terrestrial base station <b>111</b>, <b>121</b> and the non-terrestrial base station <b>131</b> to transmit a first paging signal to the communication devices <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H, when it receives from the core network CN a call or a short message addressed to the communication device <b>2</b>E, <b>2</b>F, <b>2</b>G and <b>2</b>H in the integrated location registration area TA<b>0</b> that includes at least one terrestrial communication cell <b>112</b>, <b>122</b> and at least one non-terrestrial communication cell <b>132</b>.

For example, as shown in the figure, the first paging control unit <b>309</b> causes the first paging signal to be transmitted from the terrestrial base stations <b>111</b>, <b>121</b> (the first location registration area TA<b>1</b>). This first paging signal can successfully call the communication devices <b>2</b>E, <b>2</b>F etc. that are connected to the terrestrial base stations <b>111</b> and <b>121</b> in the first location registration area TA<b>1</b>. If the call by the first paging signal is successful, the transmission of the second paging signal from the communication satellite <b>131</b> described below becomes unnecessary, thus saving the limited power of the communication satellite <b>131</b>. In addition, by having only some base stations included in the integrated location registration area TA<b>0</b> transmit the first paging signal, the network load for transmitting the paging signal can be reduced.

The first paging control unit <b>309</b> may cause the first paging signal to be transmitted from the communication satellite <b>131</b> as the non-terrestrial base station (the second location registration area TA<b>2</b>). This first paging signal can successfully call the communication devices <b>2</b>F, <b>2</b>G, <b>2</b>H etc. that are connected to the communication satellite <b>131</b> in the second location registration area TA<b>2</b>.

It is preferable for the first paging control unit <b>309</b> to cause the base station whose type was estimated by the estimation unit <b>301</b> and/or detected by the connection detection unit <b>302</b> to transmit the first paging signal. For example, it is recommended that the first paging signal be transmitted from terrestrial base stations <b>111</b>, <b>121</b>, in the case of calling the communication device <b>2</b>E that is likely to be connected to the terrestrial base stations <b>111</b>, <b>121</b> because it is within the first location registration area TA<b>1</b> (terrestrial communication cells <b>112</b>, <b>122</b>) and outside the overlapping area OA. Similarly, it is recommended that the first paging signal be transmitted from the communication satellite <b>131</b>, in the case of calling the communication device <b>2</b>G or <b>2</b>H that is likely to be connected to the communication satellite <b>131</b> because it is within the second location registration area TA<b>2</b> (satellite communication cell <b>132</b>) and outside the overlapping area OA.

When calling the communication device <b>2</b>F located in the overlapping area OA of the first location registration area TA<b>1</b> and the second location registration area TA<b>2</b>, the first paging signal is transmitted from the base station of the type (terrestrial base station <b>111</b>, <b>121</b> or non-terrestrial base station <b>131</b>) to which the communication device <b>2</b>F is likely to be connected, based on the estimation result of the estimation unit <b>301</b> and/or the detection result of the connection detection unit <b>302</b>, while the overlapping area identification unit <b>303</b> confirms that the communication device <b>2</b>F is actually located in the overlapping area OA. Conventionally, an Equipment Identity Register (EIR) is provided in the core network CN to administrate the connection authority of communication devices <b>2</b> to the wireless communication system <b>1</b>. The EIR is a database of communication devices <b>2</b> (UEs), and in addition to the communication device identification information or communication device ID, such as IMEI (International Mobile Equipment Identity), which identifies each communication device <b>2</b>, the EIR also records whether or not each communication device <b>2</b> is authorized to connect to the wireless communication system <b>1</b> (especially terrestrial communication systems such as 5G wireless communication system <b>11</b>), or its classification such as “White”, “Black” or “Grey”. For example, a “White” communication device <b>2</b> with connection authority is allowed to connect to the wireless communication system <b>1</b>, while a “Black” communication device <b>2</b> without connection authority is prohibited from connecting to the wireless communication system <b>1</b>. Also, a “Grey” communication device <b>2</b>, whose connection authority is not yet determined, is registered in the EIR.

Since conventional EIRs are designed mainly for terrestrial communication systems such as 5G wireless communication system <b>11</b>, they might not be suitable for wireless communication systems <b>1</b> where terrestrial communication systems and non-terrestrial communication systems such as satellite communication systems <b>13</b> coexist. For example, if the communication device <b>2</b>F in the overlapping area OA of the first location registration area TA<b>1</b>, which is a part of the terrestrial communication system, and the second location registration area TA<b>2</b>, which is a part of the non-terrestrial communication system is classified as “White” in the EIR, it is unclear whether it has connection authority for both terrestrial communication system and non-terrestrial communication system or for one of them. Similarly, if the communication device <b>2</b>F in the overlapping area OA is classified as “Black” in the EIR, it is unclear whether it does not have connection authority for both terrestrial communication system and non-terrestrial communication system or for one of them. The communication control apparatus <b>3</b> according to the present embodiment administrates the connection authority for each of the terrestrial communication system and non-terrestrial communication system individually.

The communication device administration unit <b>314</b> registers and administrates any communication devices <b>2</b> (such as communication devices <b>2</b>E to <b>2</b>I in FIG. <b>7</b>) that can communicate with at least any of the terrestrial communication system and non-terrestrial communication system in the EIR or communication device specific information retention unit in the core network CN.
